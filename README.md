# منصة التقويم المستمر – التطبيق الثاني

واجهة ثانية لمنصة التقويم المستمر بمدرسة الشهيد أحمد فقير (أولاد يعيش).

- لا يحتوي هذا المستودع على أي بيانات للتلاميذ ولا على رموز الدخول ولا على مفتاح الناظر.
- كل البيانات تبقى في جدول Google الخاص بالمدرسة، ويصل إليها التطبيق عبر خادم Apps Script نفسه الذي يستعمله التطبيق الأول.
- الإعداد الوحيد: ضع رابط خادم Apps Script (Web app URL) في الملف `config.js`.
